## 製品概要
本アプリは、本・漫画・アニメ・映画・ドラマの5つのジャンルについて、作品の感想や、触れたときに感じたことを記録できるアプリです。作品名だけでなく、そのときの気持ちや考えも一緒に残すことで、単なる視聴・読書履歴ではなく、自分が作品から何を受け取ったのかを記録できます。
記録はタイムライン形式で蓄積され、過去にどんな作品と出会い、何を感じていたのかを時系列で振り返ることができます。記録を重ねると、自分だけの街が少しずつ発展します。街の変化を通して、作品との出会いや感想が積み重なっていく様子を目で見て楽しめます。
街づくりは、記録を続けるきっかけとなると同時に、自分がこれまでどんなコンテンツに触れてきたかを実感する手がかりにもなります。過去の記録を読み返して当時の気持ちを思い出すことも、記録をもとに誰かに作品をすすめることも、利用者自身が自由に選べます。
コンテンツを楽しんだ経験を、その場限りのものにせず、あとから思い出したり誰かと共有したりできる形で残す。本アプリは、記録と街づくりを通じて、作品との出会いを自分だけの思い出として育てていく体験を提案します

### 背景(製品開発のきっかけ、課題等）
現代では、本や漫画、アニメ、映画、ドラマなど、幅広いコンテンツを手軽に楽しめます。一方で、日々多くの作品に触れるなかで、以前楽しんだ作品の名前や、どこに心を動かされたのかを忘れてしまうことがあります。「面白かった」という感覚は残っていても、何に惹かれたのか、当時どんなことを考えていたのかまでは思い出せないことも少なくありません。
私たちは、コンテンツをたくさん楽しむこと自体ではなく、作品に触れたときの感情や考えが、記録されないまま時間とともに失われてしまうことに着目しました。作品との出会いは、その瞬間だけの楽しみにとどまらず、自分の好みや関心を知る手がかりになったり、後から誰かにすすめるきっかけになったりします。しかし、気持ちを残しておく場所がなければ、そうした経験を振り返ったり、次の楽しみにつなげたりすることは簡単ではありません。
そこで、作品の感想やそのときの思いを気軽に記録し、後から見返せるアプリを考えました。記録を続ける動機として、自分だけの街が少しずつ育つ仕組みを取り入れています。振り返りを義務にするのではなく、街の成長を楽しみながら自然に記録を残し、思い出したいときや誰かに作品をすすめたいときに活用できる。そんなコンテンツとの付き合い方を実現したいと考えています。

### 製品説明（具体的な製品の説明）
本アプリでは、本・漫画・アニメ・映画・ドラマの5つのジャンルから、記録したい作品について感想や、そのときに感じたことを書き残せます。作品についての情報だけでなく、自分がどこに心を動かされたのかも記録できるため、後から読み返したときに作品と当時の自分の両方を思い出せます。
記録した内容はタイムラインに並び、作品との出会いを時系列でたどることができます。記録を重ねると、自分だけの街が少しずつ発展します。街の成長が記録の積み重ねを目に見える形で伝え、次の記録を残す楽しさにつながります。
過去の記録を見返すタイミングや、感想を誰かに共有するかどうかは利用者が自由に決められます。街を育てながら作品との出会いを記録し、思い出したいときに振り返る。そうした自分のペースで使える体験を提供します。

### 特長
#### 1. 特長1
5つのジャンルの作品と思い出を記録
本・漫画・アニメ・映画・ドラマの感想や、作品に触れたときの気持ちを記録できます。作品名だけでなく、自分が何を感じたのかも残せるため、作品との出会いを自分だけの記録として蓄積できます。
#### 2. 特長2
タイムラインで過去の記録を振り返る
記録はタイムライン形式で時系列に並びます。過去にどんな作品に触れ、何を感じていたのかをたどりながら、当時の自分や作品の魅力を思い出すことができます。
#### 3. 特長3
記録に応じて自分だけの街が育つ
作品を記録するたびに街が発展し、コンテンツとの出会いの積み重ねが目に見える形になります。街の変化を楽しみながら、次の記録を残すきっかけを得られます。

### 解決出来ること
楽しんだ作品の名前や、そのときに感じたことを忘れてしまい、後から思い出せないという課題に対して、作品と感想を一緒に記録し、タイムラインで振り返れる場を提供します。
記録を積み重ねることで、自分がどんな作品に触れ、何に心を動かされてきたのかをたどれるようになります。また、街づくりによって記録を続ける楽しさを生み出し、コンテンツとの出会いを思い出や誰かにすすめる作品として活用しやすくします。

### 今後の展望
今後は、記録できる作品数の上限を拡大するとともに、記録を続ける楽しさが深まるよう、街づくり機能をさらに充実させていきます。
また、現在のPCでの利用に加えて、スマートフォンからも手軽に作品や感想を記録できるよう、対応を進めていきます。

### 注力したこと（こだわり等）
* 作品の情報だけでなく、そのときの気持ちも残せること
作品名や鑑賞履歴だけでは、後から当時の体験を思い出すのは難しいと考えました。感想や心に残ったことも一緒に記録できるようにし、作品と自分の思い出を結びつけています。
* 記録の積み重ねを、街の成長として見える形にすること
書いた記録がタイムラインに並ぶだけでなく、街の発展にもつながる仕組みにしました。自分が作品と出会ってきた歩みを街の変化として感じられるため、記録を続ける楽しさが生まれます。
